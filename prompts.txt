#### Day 13 (Sep 7) — Modules 12 + 13: ZXing QR Generator + Image Endpoint

**Time: ~2.5 hrs**

**Files:**
- `util/QrGenerator.java`
- Update `SessionController.java` — add QR image endpoint

**QrGenerator.java:**

```java
public class QrGenerator {
    /**
     * Generates a QR code PNG as a byte array.
     * @param content The text/URL to encode
     * @param width   Image width in pixels (e.g., 300)
     * @param height  Image height in pixels (e.g., 300)
     * @return PNG bytes
     */
    public static byte[] generatePng(String content, int width, int height);
}
```

**Implementation:**
1. Create `BitMatrix` using `QRCodeWriter.encode(content, BarcodeFormat.QR_CODE, width, height)`
2. Convert to `BufferedImage` using `MatrixToImageWriter.toBufferedImage(bitMatrix)`
3. Write to `ByteArrayOutputStream` as PNG
4. Return byte array

**QR image endpoint:**

| Method | Endpoint | What it does |
|--------|----------|-------------|
| `GET` | `/api/sessions/{id}/qr` | Generate a short-lived JWT scan token → embed in URL → encode URL as QR PNG → return `image/png` |

**The URL encoded in the QR:**
```
https://your-frontend.vercel.app/scan?token=eyJhbGciOiJIUzI1NiJ9...
```

For local dev, use `http://localhost:5173/scan?token=...`

**Flow:**
1. Look up session → verify not expired/closed
2. Generate a 15-second scan JWT: `JwtUtil.generateScanToken(sessionId)`
3. Build the scan URL: `baseUrl + "/scan?token=" + scanToken`
4. Generate QR PNG: `QrGenerator.generatePng(scanUrl, 300, 300)`
5. Return with `Content-Type: image/png`

**✅ Done when:** Hit the endpoint in Postman → see a QR code image. Scan it with your phone camera → opens a URL containing a JWT. Decode the JWT → it contains the session ID and expires in 15 seconds.
